# لوحة وأداة توليد تراخيص AN POS (License Generator)

أداة خاصة بالناشر والمطور لإصدار مفاتيح التفعيل الموقعة رقمياً بتقنية **Ed25519** لعملاء نظام AN POS مع واجهة تحكم رسومية فاخرة وسهلة.

---

## 🚀 التشغيل السريع للواجهة الرسومية (GUI)

افتح سطر الأوامر في مجلد `license-generator` وشغل:
```bash
node ui.js
# أو
npm start
```
* سيفتح المتصفح تلقائياً على الرابط: `http://localhost:5566`
* تتيح لك اللوحة:
  1. إدخال بيانات المتجر، اسم العميل، هاتفه، وتحديد مدة الاشتراك (مدى الحياة / سنة / مخصص).
  2. تحديد عدد أجهزة الجوال المسموح باقترانها مع المحل.
  3. توليد الكود الموقع رقمياً بضغطة زر.
  4. نسخ الكود، تحميل ملف `.lic`، أو إرساله للعميل عبر واتساب مباشرة بنص جاهز ومصمم.
  5. حفظ سجل كامل بجميع التراخيص الصادرة مع إمكانية التصدير إلى **Excel (CSV)**.

---

## 💻 الاستخدام من سطر الأوامر (CLI)

إذا كنت تفضل استخدام سطر الأوامر مباشرة:

### 1. توليد مفتاح لعميل
```bash
# الصيغة: node generate-license.js [معرف_المتجر] [عدد_الأيام] [أقصى_أجهزة_جوال]

# ترخيص مدى الحياة (0 أيام) مع 5 أجهزة جوال:
node generate-license.js ST0001 0 5

# ترخيص سنوي (365 يوم) مع 10 أجهزة جوال:
node generate-license.js SHOP99 365 10
```

### 2. إعادة توليد زوج المفاتيح (إذا لزم الأمر)
```bash
node generate-keypair.js --force
```

## 🔒 تنبيه أمني
- ملف `private-key.pem` هو الختم السري الخاص بك. احتفظ به بأمان ولا تشاركه أبداً.
- تم إدراج `private-key.pem` و `licenses-history.json` و `*.lic` تلقائياً ضمن `.gitignore` لمنع رفعها إلى Git.
