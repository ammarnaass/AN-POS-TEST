## 5. جدول تسلسل الحالات

| الخطوة | الحالة | المخرجات | مدة تقديرية |
|--------|--------|----------|-------------|
| 1 | مسح QR | raw string | < 100ms |
| 2 | فك التشفير TLV | JSON object | < 50ms |
| 3 | التحقق المحلي | signature valid/invalid | < 200ms |
| 4 | الاتصال بـ ZATCA | API response | < 2s |
| 5 | تسجيل السجل | DB insert | < 100ms |
| 6 | عرض النتيجة | UI update | < 50ms |
| **المجموع** | | | **< 2.5s** |
